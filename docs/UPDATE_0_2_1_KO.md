# 0.2.1: 외부 도구 실행·자동 큐·보관함 갱신 수정

- Windows PyInstaller 앱이 Codex 등 외부 프로그램에 번들 DLL 검색 경로를 전달하지 않도록 실행 시 경로를 초기화하고 즉시 복원합니다. 번들 내부 PATH도 외부 도구 환경에서 제외합니다.
- 0xc0000142 종료 코드를 식별해 Codex 시작 실패로 안내합니다. 오류 코드는 여러 원인이 가능하며 사용자 PC의 오류 해결을 확정한 것은 아닙니다.
- AI 연결 사용을 켜면 대기 작업을 주기적으로 확인해 자동으로 시작합니다. 처리 중 새 문항을 추가하거나 작업 종료 시점에 작업이 추가되어도 이어서 가동합니다.
- 사용자가 취소했거나 인증·네트워크 오류로 중단한 뒤에는 무한 재시작하지 않습니다. 원인 해결 후 작업 큐의 재개를 누르세요.
- 문제 보관함에 새로고침 버튼과 자동 새로고침(작업 중)을 추가했습니다. 작업 중 보관함을 보고 있으면 약 1.5초 간격으로 목록과 상태를 갱신합니다.
- 갱신 시 선택한 문항과 스크롤 위치를 유지하고 갱신 시각을 표시합니다.

업데이트: 기존 앱 작업 취소 → 백업 → 완전 종료 → 새 ZIP을 새 폴더에 전체 압축 해제 → 새 EXE 실행.
자동 처리 전에 AI 연결 사용을 켜세요. 인증/한도/CLI 실행 오류가 있으면 작업 큐 사유를 확인하세요.

로컬 45개 테스트 통과. Windows 빌드에는 배포 EXE에서 외부 시스템 프로그램을 실행하는 검사를 추가했습니다.
실제 사용자 PC에서 0xc0000142가 재발하면 오류 창의 실행 파일명과 작업 큐 사유가 추가로 필요합니다.
