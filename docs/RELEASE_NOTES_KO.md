Windows x64 수학 문제은행 개발판입니다.

아래 Assets에서 **MathBankDesktop-Windows-x64.zip**을 내려받으세요. GitHub 로그인 없이 받을 수 있습니다.

1. ZIP 파일을 마우스 오른쪽 버튼으로 클릭하고 **모두 압축 풀기**를 선택합니다.
2. 압축을 푼 폴더에서 **MathBankDesktop.exe**를 실행합니다.
3. `_internal` 등 함께 제공된 파일을 EXE와 같은 위치에 유지합니다.
4. 앱의 자료실에서 본인의 HWP/HWPX를 선택합니다.

Python·Qt·출력기·한글 폰트가 포함됩니다. 원본 시험지·정답·학생 DB는 배포물에 포함하지 않습니다.

공개 ZIP은 Windows 러너에서 단위 검사·HWPX 통합 검사·패키징된 EXE의 창 생성/수식/PDF 검사를 통과한 뒤 게시합니다. 사용자 PC 설치, 실제 프린터, 한글에서 열기·편집·재저장은 별도 검증이 필요합니다.

지원 유형만 자동 수학 검증을 통과하며 미지원 유형은 보류합니다. AI는 별도 연결이 필요하고, 자동 연결 성공이나 전 단원 정확도를 보장하지 않습니다.
