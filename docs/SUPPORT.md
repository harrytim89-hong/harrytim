# 지원 범위와 제약

- 새 코드 구조: `studio/` Python 도메인·SQLite·작업 큐, QtWebEngine/QWebChannel 데스크톱 UI, Typst PDF와 python-hwpx HWPX 출력. 이전 앱 모듈/DB 로더가 없습니다.
- HWPX: manifest/spine의 본문 순서, 인라인 수식, 표/병합 셀, 텍스트 상자, 실제 참조 그림, 미주/각주를 처리합니다. 독립 순차 정답 미주 패턴은 문서 단위로 추론합니다. 번호 문단은 공백 유무·발췌 시작 번호·괄호·명시적 문제 표기·문단 자동 번호를 해석합니다. 표·글상자 안의 문항도 구조 근거로 분리합니다. 경계를 확정하지 못하면 원문을 보류 자료로 저장하며, 앱의 문항 나누기에서 시작 문단을 선택해 분리할 수 있습니다.
- HWP5: python-hwpx의 변환을 사용하며 네이티브 텍스트·수식·표·그림과 변환 XML을 대조합니다. 변환 누락·미지원 기록은 보류합니다. 모든 HWP 양식을 보장하지 않습니다.
- 입력 정답은 선택 사항입니다. 다른 문서의 같은 번호를 자동 연결하지 않습니다. 별도 정답/해설 문서의 자동 매칭 UI는 아직 제공하지 않습니다. 지원 정답 입력 경로는 같은 문제 문서에 연결된 미주와 문항별 편집입니다.
- 수식: EqEdit 문법 파서 → 정규화 MathML 트리 → 웹/Typst/HWPX. 분수·근호·첨자·행렬·경우나눔·적분 등은 표현을 처리하되 수학 자동 검증 지원 여부는 별개입니다. 미지원 태그·장식은 보류됩니다.
- 원본 그림은 개체로 보존합니다. 도형 자동 재작도, 기하 관계 추론·수치 갱신, 사진 OCR은 미지원입니다. 도형 불확실성이 있는 문항을 자동 배부하지 않습니다.
- 검증: 다항식 선형 결합·역연산, 실수 복소수 연립식, 이차 판별식, 두 일차식 나머지, 실수 대칭식, 켤레근 삼차식, 근의 거듭제곱/역수, 공통 연립식, 접선·교점, 역순 이차식, 중복인수의 나머지, 정수 매출 최적화, 복소수 식·주값 근호, 중첩 나머지, 이차·일차함수 중근 조건, 삼차식의 두 실근, 자연수 구간 최댓값/최솟값 등 명시적 정책을 지원합니다. 새로운 조건이나 미지원 유형은 AI가 답하더라도 보류합니다. 일부 유형의 자동 정책 확대는 후속 작업입니다.
- 로컬 변형은 다항식 연산·역연산만 지원합니다. AI 변형은 전 단원을 요청할 수 있으나 해당 생성물에 검증 정책이 없으면 자동 사용하지 않습니다. 사고변형의 교육적 타당성을 일반적으로 완전 판정하는 기능은 없습니다.
- PDF: 기본 2단 4문항, 긴 문항은 연속 흐름, 보기 폭 기반 배치, 해설 2단 연속 흐름, 빠른정답, 교재 단원 헤더. HWPX는 별도 생성기이며 본문·수식·표는 편집 가능, 그림은 래스터 개체입니다. HWPX는 PDF와 동일 조판을 보장하지 않습니다.
- HWPX 구조 재열기·개체 참조 검사는 수행합니다. 이 개발 환경에는 한글 데스크톱이 없어 **한글에서 열기/편집/재저장 검증은 미완료**입니다.
- 채점: 객관식, 안전한 수식 문법으로 해석 가능한 단답, 수동 부분점수. 복잡한 미판정 동치나 서술형 답은 채점 대기로 남깁니다. 순위·백분위·타 학교 예상점수는 생성하지 않습니다.
- 시험 자동 조건 조립은 현재 검색·필터→전체 결과 선택→순서/배점 편집 방식입니다. 문항 수 자동 추천·정교한 교육과정 유형 트리·일반 도형 재작도·다양한 답지 양식 매칭은 후속 작업입니다.
- Windows 자동 빌드는 새 소스 테스트와 패키징 후 `--self-test`의 화면·파일 입출력 검사를 수행합니다. 사용자 PC의 한글 및 실제 프린터 검증을 대신하지 않습니다.

의존성은 `requirements.lock`에 고정합니다. PySide6/Qt는 수정하지 않은 동적 라이브러리로 배포하고 교체·디버깅을 제한하지 않습니다. 폰트는 Noto Sans CJK와 라이선스를 함께 배포합니다. 런타임에 의존 패키지를 다운로드하지 않습니다.
