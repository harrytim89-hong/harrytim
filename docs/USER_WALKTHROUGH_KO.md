# MathBank Desktop 0.1.0 상세 사용 설명서

이 설명서는 Windows 빌드 `008479d`의 실제 화면과 버튼을 기준으로 작성했습니다.
아직 요구서 전체가 완성된 제품은 아니며, 실제 AI 인식 연결·고급 분리·도형 편집 등은 추가 작업이 필요합니다.

## 1. 다운로드와 실행

1. https://github.com/harrytim89-hong/harrytim/actions/runs/40908348994 를 엽니다.
2. GitHub에 로그인합니다.
3. 페이지 아래 Artifacts에서 `MathBankDesktop-Windows-x64`를 다운로드합니다.
4. ZIP을 우클릭해 **모두 압축 풀기**를 선택합니다. ZIP 안에서 EXE를 바로 실행하지 않습니다.
5. 압축을 푼 폴더의 `MathBankDesktop.exe`를 더블클릭합니다.

EXE와 `_internal` 폴더를 함께 유지하세요. 다른 위치로 옮길 때에도 전체 폴더를 옮깁니다.
배포판 실행에는 Python·Node 설치가 필요하지 않습니다. 아직 설치 마법사 형태는 아닙니다.
바탕화면에서 실행하려면 EXE의 바로가기를 만드세요. EXE 자체를 바탕화면으로 이동하면 안 됩니다.
Windows가 차단하면 표시된 메시지를 확인하세요. 보안 프로그램 전체를 끄는 방식은 권장하지 않습니다.

## 2. 화면별 역할

| 왼쪽 메뉴 | 하는 일 |
|---|---|
| 01 PDF 자료실 | PDF 등록, 자동 처리 시작, 마우스로 문항 영역 추가 |
| 02 문제 보관함 | 검색, 원본 확인, 본문·수식·답·풀이 편집, 재처리 |
| 03 시험지 · 과제 | 선택 문항으로 시험지 구성, 문제지·빠른답·해설·DOCX 출력 |
| 04 학생 · 성적표 | 학생 등록, 시험 배정, 수동 채점, 성적표 작성·출력 |
| 05 작업 큐 | 자동 처리의 진행·실패·일시정지 확인, 취소·재개 |
| 06 AI · 백업 설정 | Codex 연결 진단, 연결 사용, 백업·복원, 오프라인 요청 교환 |

## 3. 처음에는 AI 없이 한 문항으로 연습하기

현재 환경에서는 실제 AI 이미지 요청이 접근 거부·시간 초과로 실패했습니다.
사용자 PC에서도 자동 처리가 바로 성공한다고 보장할 수 없습니다.
아래 순서로 먼저 저장·편집·출력 흐름을 확인할 수 있습니다.

1. PDF 자료실 → **PDF 등록** → PDF 선택 → 과정에 `공통수학2`처럼 입력합니다.
2. 등록된 PDF 행을 클릭합니다.
3. **영역 직접 추가** → 페이지 번호 입력 → 원본에서 문제 하나의 본문·보기·그림 전체를 드래그합니다.
4. **선택 영역을 문항으로 저장**을 누릅니다.
5. 문제 보관함에서 새 문항을 선택하고 **원본 · 편집**을 누릅니다.
6. 원본을 보면서 본문, 보기, 빠른답, 풀이, 단원, 난이도를 입력합니다.
   도형이 없는 문제의 도형 JSON은 `[]`로 둡니다.
7. **수식 · 도형 미리보기**에서 표시를 확인하고 **저장**합니다.
8. 보관함에서 문항을 다시 선택한 뒤 시험지 · 과제로 이동합니다.
9. **보관함 선택 문항으로 만들기** → 제목·레이아웃·문항당 배점을 입력합니다.
10. 자동 검사 미완료 안내에서는 **예외 표시 초안**을 선택합니다.
11. 생성된 시험지를 선택하고 **문제지 → PDF 저장**을 실행합니다.

이 결과는 예외가 표시된 초안입니다. 수동 저장이나 초안 출력이 자동 원문 검사를 통과했다는 뜻은 아닙니다.
교사가 승인해야 넘어가는 절차는 없지만, 자동 검사 결과 자체를 없애거나 통과로 바꾸지는 않습니다.

## 4. PDF 등록과 자동 처리

### PDF 등록

- PDF 자료실 → **PDF 등록**을 누르고 파일을 선택합니다.
- 과정에는 교재의 실제 과정(예: 공통수학1, 공통수학2)을 입력합니다. 모르면 비워둘 수 있습니다.
- 같은 내용의 PDF를 다시 선택하면 중복 등록 안내가 나옵니다.
- 암호화된 PDF는 암호를 해제한 사본이 필요합니다.
- 현재 단순한 한 페이지 문항부터 시험하는 것이 좋습니다. 다페이지 문항·복잡한 공통지문 등은 미완료 영역입니다.

### AI 연결 준비

앱의 Python·Qt 런타임과 AI 연결 도구는 별개입니다. **Codex CLI는 배포 파일에 포함되어 있지 않습니다.**
ChatGPT 웹사이트에 로그인된 것만으로 앱의 CLI 연결이 완료되는 것도 아닙니다.

1. 공식 안내 https://developers.openai.com/codex/cli 또는 https://github.com/openai/codex 에 따라 Windows용 Codex CLI를 준비합니다.
2. Codex CLI에서 **ChatGPT 계정 로그인**을 완료합니다. CLI가 설치된 환경에서는 `codex login`을 사용합니다.
3. 앱이 이미 실행 중이었다면 재시작해 설치된 CLI 경로를 다시 인식하게 합니다.
4. AI · 백업 설정 → **연결 진단**을 누릅니다.
5. ChatGPT 로그인이 확인되면 **Codex 구독 연결 사용 (현재 세션)**을 체크합니다.

현재 앱은 자체 설치·브라우저 로그인 버튼을 제공하지 않습니다. CLI 설치·로그인은 외부 공식 도구에서 해야 합니다.
로그인 확인은 실제 이미지 처리 성공을 뜻하지 않습니다. 구독 한도·서비스 연결 상태에 따라 실패할 수 있습니다.
API 키 로그인은 구독 연결 성공으로 취급하지 않으며, 유료 API로 자동 전환하지 않습니다.
연결 사용 체크는 현재 실행 세션에만 적용되므로 재시작 후 다시 켜야 합니다.

### 자동 처리 실행

1. PDF 자료실에서 자료 행을 선택합니다.
2. **자동 처리 시작**을 누릅니다.
3. 작업 큐에서 진행 상황을 확인합니다.
4. 정상 완료 문항은 문제 보관함에 저장되며 별도 교사 승인 없이 시험지에 사용할 수 있습니다.

AI 연결을 켜지 않은 상태에서 자동 처리를 누르면 작업은 큐에 저장되고 안내가 나옵니다.
연결을 켠 뒤 작업 큐의 **대기 · 중단 작업 재개**를 누르면 됩니다.

## 5. 작업 큐와 오류 처리

| 상태 | 의미 / 조치 |
|---|---|
| queued | 순서 대기 중 |
| running | 현재 처리 중 |
| done | 해당 작업 완료. 문항의 원문·정답·풀이 상태는 보관함에서 별도 확인 |
| paused | 인증·네트워크·시간 초과 등으로 일시정지. 원인을 해결한 뒤 재개 |
| exception | 처리 예외. 사유 확인 후 선택 재시도 또는 선택적 편집 |
| cancelled | 사용자 취소. 필요 시 재개 |
| stale | 편집 전에 시작한 옛 결과이므로 최신 문항에 반영하지 않음 |
| skipped | 빈 페이지·정답 페이지 등으로 판단하여 문제 분리 대상에서 제외 |

- **진행 작업 취소**: 현재 자동 처리의 중단을 요청합니다.
- **대기 · 중단 작업 재개**: 대기·일시정지·취소 작업을 이어갑니다. 기존 예외를 모두 자동으로 다시 돌리지는 않습니다.
- **선택 예외 재시도**: 표에서 예외·중단 작업을 선택한 뒤 누릅니다.
- 문항 판독은 서로 다른 해상도·방법으로 최대 3회 시도한 뒤 예외로 남깁니다.
- 인증 오류·한도 초과가 해결되지 않은 상태에서 같은 버튼을 계속 누르지 마세요.
- 처리 중 앱을 닫으면 먼저 작업 취소를 요청합니다. 종료 안내 후 잠시 기다렸다 다시 닫으세요.
- 다시 시작했을 때 중단 작업은 자동 완료 처리되지 않으며 재개 대기로 남습니다.

## 6. 보관함 검색·수정

검색창에 본문·단원·문항번호를 입력하고 **검색**을 누릅니다. 기본 목록은 페이지당 50개입니다.
**이전/다음**으로 이동하고, **처리 예외만**으로 문제가 있는 문항을 모아볼 수 있습니다.
본문 검색은 현재 단순 문자열 검색이며, 고급 교재별·다차원 필터는 미완료입니다.

원문·정답·풀이는 서로 다른 검사입니다. 원문이 통과했어도 정답/풀이 검사가 실패할 수 있습니다.
그 경우 문제지 본문은 사용 가능해도 빠른답·해설 출력은 제한될 수 있습니다.

문항을 선택하고 **원본 · 편집**을 누르거나 더블클릭합니다.
왼쪽에 원본 크롭, 오른쪽에 편집 필드가 표시됩니다. 현재 다중 원본 영역의 완전한 비교 UI는 미완료입니다.

| 필드 | 입력 방법 |
|---|---|
| 본문 | 일반 한글과 `$LaTeX$` 수식 |
| 보기 | 한 줄에 보기 하나. 번호는 출력 시 자동 부여 |
| 빠른답 | 정답 값 또는 선택지 번호·값 |
| 풀이 | 한 줄에 한 단계 |
| 구조화 도형 JSON | 도형 없는 경우 `[]`. 시각적 도형 편집기가 아닌 개발판 기능 |
| 단원 | 단원명 입력 |
| 난이도 | 1~5 선택 |

수식 예시:

```text
$x^2+1$
$\frac{1}{2}$
$\sqrt{x+1}$
$y=|x+1|-|x-2|$
```

수식의 `$`는 양쪽을 맞추세요. **수식 · 도형 미리보기**로 확인하고 **저장**합니다.
저장한 수동 수정값은 백그라운드 생성 결과가 덮어쓰지 않도록 보호합니다.
관련 검사는 다시 대기 상태가 되고, AI 사용이 켜져 있으면 재검사를 시작합니다.
수동 저장을 자동 검사 통과로 취급하지 않습니다.

## 7. 시험지 만들기

1. 문제 보관함에서 필요한 문항의 행을 선택합니다.
2. 여러 문항은 Ctrl+클릭, 연속된 범위는 Shift+클릭으로 선택합니다.
3. 선택 상태로 시험지 · 과제 화면으로 이동합니다.
4. **보관함 선택 문항으로 만들기**를 누릅니다.
5. 제목, 레이아웃, 문항당 배점을 입력합니다.

현재 선택은 표시된 보관함 페이지를 기준으로 합니다. 여러 페이지를 넘나드는 선택 바구니는 없습니다.
새로 검색하거나 목록을 갱신하면 선택을 다시 해야 할 수 있습니다.
현재 모든 문항에 같은 배점이 적용되며, 개별 배점·정렬·여백 편집 UI는 미완료입니다.

| 화면의 레이아웃 값 | 의미 |
|---|---|
| one | 1단 |
| two | 2단 |
| grid | 2열 그리드. 매 페이지 정확히 4문항 고정 배치는 아직 아님 |

예외 문항이 있으면:

- **완료 문항만 사용**: 안내된 예외 문항을 제외합니다. 남는 문항이 0개면 생성할 수 없습니다.
- **예외 표시 초안**: 예외 사유를 문항별로 표시한 초안을 만듭니다.
- **재처리 후 만들기**: 예외 재처리를 예약합니다. 처리 후 다시 시험지를 생성해야 합니다.

저장된 시험지는 당시 내용·답·배점·분류를 보존합니다.
이후 문제은행을 고쳐도 이미 만든 시험지는 자동 갱신되지 않습니다. 변경 내용을 반영하려면 새로 생성하세요.

## 8. 문제지·정답·해설·DOCX 출력

시험지 목록에서 시험지를 먼저 선택합니다.

- **문제지**: 학생용 문제 본문.
- **빠른답**: 정답만 모은 출력.
- **상세 해설**: 정답과 단계별 풀이.
- **DOCX 저장**: Word 형식 문제지.

미리보기 창에서 수식·글꼴 렌더링이 완료되면 **PDF 저장**과 **프린터로 인쇄**가 활성화됩니다.
PDF는 저장 위치를 선택하고, 화면에 저장 완료 메시지가 나오는지 확인합니다.
인쇄는 프린터 선택 창에서 실제 프린터를 지정합니다. PDF 저장과 프린터 출력은 별도 동작입니다.
실제 프린터 출력은 사용자 PC에서 추가 검사가 필요합니다.

DOCX의 수식은 Word 네이티브 수식 객체입니다. 현재 도형이 있는 문항은 명시적으로 내보내기를 중단합니다.
수식 변환에 실패한 경우에도 해당 위치를 알리고 저장을 중단합니다.
Word·한컴오피스에서 실제 열기/편집은 미검증이며 HWP/HWPX 직접 저장은 없습니다.
긴 문항·공통지문·복잡한 그림은 페이지 경계 처리 미완료 부분이 있으므로 실제 결과를 확인하세요.

## 9. 학생 등록과 시험 배정

1. 학생 · 성적표 → **학생 등록**.
2. 이름, 반, 학년, 교사 메모, 학교급(중등/고등)을 입력하고 저장합니다.
3. 시험지 · 과제 화면에서 배정할 시험지 행을 선택합니다.
4. 학생 · 성적표로 돌아와 학생 행을 선택합니다.
5. **선택 시험 배정**을 누르고 제출일을 `2026-11-07` 같은 YYYY-MM-DD 형식으로 입력합니다.
6. 아래 배정 목록에 학생·시험지·제출일·상태가 나타나는지 확인합니다.

배정은 앱 안에 기록하는 기능입니다. 학생에게 파일·문자·이메일이 자동 발송되지는 않습니다.
배부할 파일은 PDF로 저장해 직접 전달하세요. 학생명 자동 삽입·일괄 배부는 아직 미완료입니다.

## 10. 채점과 성적표

학생 화면의 **아래 배정 목록**에서 채점할 과제를 선택하고 **채점 · 성적표 작성**을 누릅니다.
학생 명단만 선택한 상태가 아니라 배정된 시험을 선택해야 합니다.
현재 채점은 교사가 학생 답안을 보고 직접 기록하는 방식입니다. 학생 답안 자동 인식 기능은 없습니다.

| 선택 값 | 의미 |
|---|---|
| O | 정답. 해당 문항의 전체 배점 반영 |
| X | 오답. 0점 |
| — | 미응답. 0점 |
| 미채점 | 아직 채점하지 않음. 오답으로 확정하지 않음 |
| 부분점수 | 오른쪽 칸에서 0~문항 배점 사이의 점수 지정 |

부분점수 칸의 숫자는 상태가 **부분점수**일 때만 반영됩니다.
미채점이 남아 있으면 성적표에 최종 점수 미산출임을 표시합니다.

다음 문구는 현재 교사가 직접 작성합니다. 고품질 AI 분석 자동 생성은 미완료입니다.

- **01 / 부족한 점과 보완 방법**: 실제 문항 결과를 근거로 진단과 연습을 작성합니다.
- **02 / 잘한 점과 강점**: 실제 맞힌 문항·확인된 풀이를 근거로 작성합니다.
- **TEACHER’S NOTE / 총평**: 시험 구성과 현재 성취, 보완할 학습 내용을 정리합니다.
- **교사 입력 예상등급**: 선택 입력입니다. 앱이 자동 산출한 학교 등급이 아닙니다.

**저장 · 성적표 미리보기**를 누르면 채점·서술을 저장하고 성적표가 열립니다.
중등/고등은 학생 등록 시 선택한 학교급에 따라 달라집니다. 기본 레이아웃은 A4 2페이지입니다.
저장한 성적표는 **저장 성적표 보기**로 다시 열어 PDF 저장·인쇄할 수 있습니다.
수정하려면 해당 배정을 선택해 채점 · 성적표 작성을 다시 열고 저장합니다.

## 11. 오답 보완

채점된 배정을 선택하고 **오답 보완 문항 찾기**를 누릅니다.
X·미응답·부분점수가 기록된 문항의 단원 중 하나를 선택하면 해당 단원으로 보관함을 검색합니다.
다른 문항을 직접 선택해 새 시험지·과제를 만들 수 있습니다.
현재는 단원 검색 연결 기능이며, 정교한 유사문항 추천이나 검증된 변형문항 자동 생성은 아닙니다.

## 12. 백업과 복원

### 백업

1. 진행 중인 자동 작업을 완료하거나 취소하고 종료를 기다립니다.
2. AI · 백업 설정 → **백업 ZIP 저장**.
3. 저장 위치를 선택합니다.
4. 백업 완료 메시지를 확인합니다.

백업에는 DB, 문항·학생·시험·성적표 기록, 연결된 원본 PDF와 해시 목록이 포함됩니다.
별도 위치에 내보낸 PDF·DOCX 파일까지 자동으로 모으는 기능은 아닙니다. 그런 파일은 따로 보관하세요.

### 복원

1. AI · 백업 설정 → **새 폴더로 복원**.
2. 백업 ZIP을 선택합니다.
3. 복원할 새 폴더를 만들 상위 위치를 선택합니다.
4. 생성된 `MathBank-restored-날짜-시간` 경로를 확인합니다.

복원은 현재 데이터에 합치거나 덮어쓰는 기능이 아닙니다. 앱이 복원 폴더로 자동 전환되지도 않습니다.
현재는 앱 종료 후 사용자 환경변수 `MATHBANK_DATA`를 복원 폴더 경로로 지정해야 합니다.
Windows 검색 → '계정의 환경 변수 편집' → 사용자 변수 새로 만들기/편집:
이름 `MATHBANK_DATA`, 값은 복원 폴더의 전체 경로(따옴표 없이)입니다.
설정 후 앱을 다시 실행하고 문항·학생·과제 수를 확인하세요.
처음 사용하는 경우 원래 폴더와 백업을 삭제하지 않은 상태에서 전환을 확인하는 것이 좋습니다.

기본 데이터 위치는 `%LOCALAPPDATA%\MathBankDesktop`입니다.
Win+R을 누르고 이 경로를 입력하면 열 수 있습니다.
설치/실행 폴더와 운영 데이터 위치는 다르므로 EXE 폴더를 옮긴다고 기록이 함께 이동하는 것은 아닙니다.
다른 PC로 옮길 때에는 앱 전체 폴더와 백업 ZIP을 각각 준비하세요.

## 13. 오프라인 AI 요청 교환 (고급 기능)

1. 문제 보관함에서 문항을 선택합니다.
2. AI · 백업 설정 → **문항 요청 패키지 내보내기**.
3. ZIP 안의 원본 크롭과 request.json을 확인합니다.
4. 외부에서 응답을 준비할 때 request.json의 문항 식별 정보와 응답 구조를 그대로 사용합니다.
5. 앱의 **결과 JSON 가져오기**로 응답을 읽습니다.

일반 채팅 답변을 복사한 TXT 파일은 바로 가져올 수 없습니다. 지정된 JSON 구조가 필요합니다.
원본 해시·문항 ID·버전이 다르면 거부하고, 사용자 수정값도 자동 덮어쓰지 않습니다.
가져온 결과는 독립 검사 대기이므로, 이 기능만으로 AI 연결 없이 검증 완료 상태가 되지는 않습니다.
독립 검사 결과까지 오프라인으로 가져오는 전체 흐름은 미완료입니다.

## 14. 자주 만나는 상황

| 상황 | 확인할 것 |
|---|---|
| EXE가 실행되지 않음 | ZIP 전체 압축 해제 여부, `_internal` 동반 여부, Windows 오류 문구 |
| PDF 등록 후 문항이 안 보임 | 등록만 했는지, 자동 처리/영역 직접 추가를 했는지, 작업 큐 상태 |
| Codex CLI 없음 | 공식 CLI 설치 후 앱 재시작. 앱 자체 실행과 AI 연결은 별개 |
| 로그인은 확인되는데 처리 실패 | 작업 큐의 접근 거부·한도·네트워크·시간 초과 사유 확인 |
| 시험지 생성 시 항목 선택 안내 | 보관함에서 문항 선택 후 시험지 화면으로 이동했는지 |
| 완료 문항만 사용했는데 생성 실패 | 선택 문항이 모두 검사 미완료라 남는 문항이 0개인지 |
| 수정한 문제가 기존 시험지에 반영되지 않음 | 정상적인 스냅샷 동작. 새 시험지를 생성해야 함 |
| 빠른답·해설만 출력 불가 | 원문 검사와 별도로 답·풀이 검사를 통과했는지 |
| PDF 버튼이 비활성 | 수식·글꼴 렌더링 대기/실패 문구 확인. 수식 구분자·표현 수정 |
| DOCX에 도형을 넣을 수 없음 | 현재 미지원. PDF 출력 사용 |
| 학생 배정이 안 됨 | 시험지 목록의 시험지와 학생 목록의 학생을 둘 다 선택했는지, 날짜 형식 |
| 성적표가 없음 | 아래 배정 목록 선택 후 채점·성적표를 저장했는지 |
| 복원 후 이전 자료가 계속 보임 | 새 복원 폴더로 `MATHBANK_DATA`를 변경하고 재실행했는지 |

오류를 문의할 때에는 사용한 버튼, 오류 문구, 발생 순서, Windows 버전을 알려주세요.
문서 샘플을 공유해야 한다면 학생 개인정보가 없는 예제로 준비하는 것이 좋습니다.

## 15. 현재 검증 범위

Windows CI에서 테스트 31개와 EXE의 창 생성·수식 렌더링·PDF 저장 검사를 통과했습니다.
이는 실제 사용자 Windows 10/11 PC의 설치·프린터·Word/한글 호환성 검사나
모든 수학 교재의 자동 인식 정확도 검증을 의미하지 않습니다.
전체 구현/미완료 항목은 IMPLEMENTATION_STATUS.md를 참고하세요.
