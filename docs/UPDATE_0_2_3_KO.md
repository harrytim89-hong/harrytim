# 0.2.3 Codex 호출 호환성 및 진단

일부 CLI 버전에서 존재하지 않는 기능 이름에 대한 `--disable` 옵션을 거부할 수 있어, 기능 비활성화는 `-c features.<name>=false` 설정으로 전달합니다. 읽기 전용 sandbox와 사용자 설정 무시는 유지합니다.

모델 사용 불가, 추론 옵션 미지원, CLI 옵션 미지원, 설정 형식, 설치 파일 누락, 인증서 오류, 로그인 세션 만료를 별도로 안내합니다. 원본 CLI 출력에는 문항과 인증 정보가 포함될 수 있어 그대로 표시하거나 저장하지 않습니다.

이 변경만으로 모든 종료 코드 1의 원인이 해결되었다는 뜻은 아닙니다. 새 버전의 큐 상단에 나타난 사유를 확인하세요. 모델 오류일 때는 지정 모델을 비우고 추론 강도를 기본값으로 저장하여 다시 시작하세요. CLI 옵션 오류일 때는 공식 CLI를 업데이트하세요.
