# MathBank Desktop 0.3.1 다운로드·실행

이 개발판은 Windows x64용 로컬 프로그램입니다.

1. 저장소의 Releases에서 `MathBank Desktop 0.3.1`을 엽니다.
2. 아래 Assets의 `MathBankDesktop-Windows-x64.zip`을 클릭합니다. 로그인 없이 받을 수 있습니다.
3. 파일이 내려받아질 때까지 기다립니다.
4. 내려받은 ZIP을 우클릭하고 모두 압축 풀기를 실행합니다.
5. 폴더 안의 MathBankDesktop.exe를 실행합니다. EXE와 _internal 등 함께 제공된 파일을 분리하지 마세요.

Python/Qt/출력기/폰트를 포함하도록 빌드합니다. 원본 시험지·정답·학생 DB는 배포에 포함하지 않습니다.
자료실에서 HWP/HWPX를 선택하고, 문항검색에서 저장 상태를 확인합니다.
정답·해설 생성은 변형·정답 생성 화면에서 별도로 실행합니다.
AI 연결은 선택 사항입니다. 지원 계산 유형만 자동 검증 통과하며 나머지는 보류합니다.

Actions의 성공 여부는 실제 실행 결과로 확인해야 합니다. 한글에서 편집·재저장, 실제 프린터와 사용자 PC 설치는 별도 확인이 필요합니다.
