# Windows 수용 검사 (아직 미실행)

검사 기록에 Windows 버전/빌드, CPU 아키텍처, 앱 버전, Codex 버전,
Word/한글 버전, 프린터 모델, PDF 파일명/해시를 남긴다.

- [ ] Windows 빌드 스크립트가 성공하고 배포 ZIP·EXE의 해시를 기록한다.
- [ ] Python·Node 없는 Windows 10/11 일반 계정에서 설치·아이콘 더블클릭으로 실행한다.
- [ ] 공백·한글 설치 경로와 운영 데이터 경로에서 PDF 등록·재시작·출력한다.
- [ ] 로그인 연결 실패/성공 및 실제 이미지 입력을 검사한다. API 인증을 구독 성공으로 표시하지 않는다.
- [ ] 대표 실제 텍스트/스캔·다단·공통지문·복잡한 도형 PDF로 누락·중복·수식·그림 관계를 측정한다.
- [ ] 원문 숫자 상수 변경이 예외가 되고 정상 문항은 계속 처리되는지 확인한다.
- [ ] 늦은 작업과 수동 편집 충돌, 중도 종료·재개, 네트워크 단절, 한도 초과를 검사한다.
- [ ] 시험지 PDF/빠른답/풀이에 내용 누락·정답 노출·작은 글씨·쪽 경계 잘림이 없는지 눈으로 확인한다.
- [ ] DOCX를 실제 Word와 한컴오피스에서 열어 수식 편집과 배치를 확인한다.
- [ ] 물리 프린터로 A4 출력하고 실패·취소 처리와 여백을 확인한다.
- [ ] 학생별 채점·미채점·부분점수와 중/고등 성적표가 실제 기록과 일치하는지 확인한다.
- [ ] 백업→새 폴더 복원 후 문항·학생·과제·성적표 수와 PDF 해시가 일치하는지 확인한다.
- [ ] 설치 업데이트/삭제 후 운영 데이터 보존을 검사한다. 자동 업데이트 롤백은 아직 미구현이다.

현재는 이 체크리스트와 빌드 구성을 준비했을 뿐, Windows 검사 통과를 의미하지 않는다.
