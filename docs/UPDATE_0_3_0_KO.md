# 0.3.0 자동처리 효율 개선

## 기본 적용

- 문항 이미지의 완전히 흰 바깥 여백만 제거합니다. 픽셀 재표본화나 해상도 축소는 없으며 아주 옅은 픽셀(254)도 보존합니다. 페이지 분리 이미지는 좌표 보존을 위해 자르지 않습니다. 스캔 배경이 희지 않으면 줄어들지 않을 수 있습니다.
- 연결 오류·취소 후 24시간 내 재개할 때 정상 전사와 독립 판독을 이어 씁니다. 최종 영상 검토는 다시 실행합니다. 예: 두 판독이 성공하고 최종 검토에서 연결이 끊긴 경우, 재개의 호출은 3회에서 1회로 줄어듭니다. 이 수치는 호출 수이며 토큰 절감률은 아닙니다.
- 체크포인트는 문항 ID/버전, 이미지 바이트, 역할, 프롬프트, 지정 또는 최근 관측 모델, 추론 설정이 일치할 때만 사용합니다. 콘텐츠 검사를 다시 통과해야 하며 원문 불일치 시 폐기합니다. 성공하면 삭제합니다. 풀이 결과가 독립 판독에 전달되지 않습니다.
- 검토 JSON의 불필요한 공백과 검토 대상이 아닌 부가 메타데이터를 제외합니다. 수학 내용·정답·해설은 유지합니다. 등록된 과목 범위를 최종 검토에도 명시합니다.
- 설정 화면에 누적 성공 호출 수, CLI가 보고한 토큰 합계와 집계된 호출 수, 재개 시 생략한 호출 수를 표시합니다. CLI가 수치를 주지 않으면 미제공으로 표시합니다. 실패 호출 사용량은 이 합계에 포함되지 않으며 구독 한도와 동일한 지표가 아닙니다.

## 선택 설정

AI · 백업 설정에서 변경 후 저장합니다.

- **독립 판독 강도 → medium**: 독립 전사만 별도 추론 강도를 사용합니다. 풀이·최종 검토의 모델과 강도는 그대로입니다. 원문 대조 실패 시 고해상도 재시도와 최종 검토가 유지됩니다. 지원하지 않는 모델이면 기존 강도 유지로 되돌리세요. 실제 교재의 정확도 비교 전에는 기본값인 기존 강도 유지를 권장합니다.
- **풀이·독립 판독 동시 실행**: 두 요청을 독립 세션으로 함께 보냅니다. 풀이가 불확실한 경우 기존 순차 실행은 독립 판독을 생략하지만 병렬 실행은 이미 호출했을 수 있어 토큰이 더 들 수 있습니다. 기본은 꺼짐입니다. 선명한 자료에서 속도를 우선할 때 켜세요.
- **동시 작업 수**는 전체 AI 호출 상한에도 적용됩니다. 2일 때도 병렬 판독을 합쳐 동시 호출 최대 2개입니다. 1로 낮추면 동시 호출도 1개입니다. 자료 전체 처리량은 요청 시간과 제한에 따라 달라집니다.

## 검증과 한계

전사, 독립 판독, 숫자·부호 대조, 원본 영상·도형·정답·풀이 검토, 산술 감사는 유지했습니다. 검증을 생략하거나 낮은 가격의 모델로 자동 전환하지 않습니다.

자동 테스트는 중단/재개, 입력·설정 변경 시 캐시 무효화, 병렬 판독의 독립성, 오류 처리, 원본 픽셀 보존을 검사합니다. 모의 응답 테스트는 실제 수학 정답률 검증을 대체하지 않습니다. 실제 사용자 교재와 로그인된 AI를 통한 전후 정확도·토큰·시간 비교는 아직 수행하지 않았으므로 절감률이나 정확도 동등성을 보장하지 않습니다.

Windows 배포 폴더 전체를 새 폴더에 풀어 실행하세요. 기존 `%LOCALAPPDATA%\MathBankDesktop` 데이터를 그대로 사용합니다. 프로그램을 종료하고 기존 앱의 백업 기능으로 자료를 보관한 뒤 교체하세요.
