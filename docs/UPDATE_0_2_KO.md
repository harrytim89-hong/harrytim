# MathBank Desktop 0.2.0 업데이트

## 정확도를 유지하는 기본 설정

권장 초기 설정은 모델/추론 강도 **기본값 유지**, 동시 작업 **2개**입니다.
기존 판독 정확도에 만족한 사용자를 위해 검증되지 않은 저가·소형 모델로 자동 변경하지 않습니다.
이번 환경에서 공식 모델 안내 조회는 접근 거부되어 최신 모델별 성능·구독 소모량 순위를 검증하지 못했습니다.
구독 연결은 API 토큰 단가로 과금하는 경로가 아니며, 모델별 사용 한도와 처리 시간은 계정/서비스에 따라 달라집니다.

설정의 `최근 CLI 실행 모델`에 실제 모델 ID가 표시되면 **최근 확인 모델 고정**을 누르세요.
이후 다음 실행부터 `--model`로 해당 모델을 지정합니다. 자동 대체 모델이나 유료 API fallback은 없습니다.
사용할 모델 ID를 아는 경우 지정 모델 칸에 직접 입력할 수도 있습니다.
추론 강도는 기존 정확도를 유지하려면 우선 기본값을 권합니다. medium/high/xhigh는 모델이 지원할 때만 사용하세요.
설정 저장은 모델·강도·동시 작업 수를 보존하지만, AI 연결 사용은 재실행 후 사용자가 다시 켭니다.
현재 처리 중이면 먼저 진행 작업을 취소하고 종료를 기다린 뒤 설정을 변경하세요.

## 속도 개선

- 독립 재판독은 본문·보기·수식 판독만 수행합니다. 답·풀이·분류를 중복 생성하지 않습니다.
- 최초 생성과 최종 원본·도형·답·풀이 검토는 유지합니다. 정상 문항의 호출 수는 여전히 3회입니다.
- 최대 2개 작업을 동시에 처리하고 원자적으로 작업을 가져와 같은 작업의 중복 실행을 방지합니다.
- 문항 처리를 페이지 분리보다 우선해, 전체 페이지 분리가 끝나기 전에도 완성 문항이 나타납니다.
- 로그인 상태 확인은 5분 동안 재사용합니다. 매번 CLI 프로세스 실행 자체는 현재 유지합니다.
- 이미 분리 완료된 페이지는 같은 자료의 자동 처리 시작을 다시 눌러도 재전송하지 않습니다.
- 문항 재처리 버튼은 명시적으로 다시 검사하는 기능입니다. 전체 응답 캐시·적응형 배칭은 아직 없습니다.
- 최근 실제 모델 및 성공 호출별 소요 시간은 로컬 DB에 기록하며 원문·학생·인증 로그는 저장하지 않습니다.

대표 실제 교재의 속도·정확도 비교는 미검증입니다. 특정 배속이나 동일 정확도를 보장하는 수치는 제시하지 않습니다.
동시 처리 중 한도·네트워크 오류가 발생하면 진행 요청을 중단하며, 동시 작업 수를 1로 낮춰 재개할 수 있습니다.

## 취소·삭제·복원

- PDF 자료실: **자료 삭제**
- 문제 보관함: **문항 삭제**
- 시험지·과제: **시험지 삭제**
- 학생·성적표: **학생 삭제**, **배정 취소 · 삭제**
- 작업 큐: **진행 작업 취소**, **대기 작업 전체 취소**
- AI·백업 설정: **휴지통 · 복원**

삭제는 휴지통 이동이며 영구 삭제가 아닙니다. 디스크의 PDF나 DB 기록을 물리적으로 지우지는 않습니다.
PDF 자료 삭제 시 소속 문항도 보관함에서 숨기고 관련 대기 작업을 취소합니다.
기존 시험지·배정·성적표는 저장 사본을 유지하므로, 학생이나 원문을 휴지통으로 옮겨도 과거 기록은 남습니다.
관련 과거 기록까지 숨기려면 해당 시험지·배정을 각각 선택해 삭제하세요.
복원은 목록을 되살리고, 취소 작업을 자동 재시작하지 않습니다. 필요할 때 작업 큐에서 재개하세요.
상위 PDF가 휴지통에 있으면 소속 문항만 복원해도 목록에 보이지 않으므로 PDF도 복원해야 합니다.
진행 중 삭제로 생길 충돌을 막기 위해 삭제는 자동 처리 종료 후 가능합니다.

## 기존 자료 유지하며 업데이트

1. 기존 앱에서 진행 작업을 취소하고 종료될 때까지 기다립니다.
2. `백업 ZIP 저장`으로 운영 자료를 백업합니다.
3. 앱을 완전히 종료합니다.
4. 새 배포 ZIP을 **별도의 새 폴더**에 전체 압축 해제합니다.
5. 새 폴더의 MathBankDesktop.exe를 실행합니다.
6. 기존과 같은 MATHBANK_DATA 또는 기본 데이터 경로를 사용하면 자료가 그대로 보입니다.
7. 데이터 확인 후 바로가기를 새 EXE로 바꿉니다. 구버전과 신버전을 동시에 실행하지 마세요.

휴지통 테이블을 기존 SQLite DB에 추가하며 문항 ID·원본·저장 시험지·성적표를 초기화하지 않습니다.
구버전 앱은 휴지통 표시를 이해하지 못하므로 업데이트 이후 구버전으로 같은 DB를 열면 삭제 항목이 다시 보일 수 있습니다.
