# MathBank Studio 시작하기

## 다운로드와 실행

1. GitHub Releases에서 **MathBankStudio-1.1.0-Windows-x64.zip**을 내려받습니다.
2. ZIP 파일을 오른쪽 클릭하여 **모두 압축 풀기**를 누릅니다.
3. 압축을 푼 `MathBankStudio` 폴더 안의 **MathBankStudio.exe**를 두 번 클릭합니다. `_internal` 폴더도 같은 위치에 있어야 합니다.

Windows 11 x64용입니다. 앱은 로컬 데스크톱 프로그램이므로 접속 주소나 서버 가입은 없습니다. 코드 서명이 없는 배포 파일이므로 Windows가 게시자를 확인할 수 없다고 표시할 수 있습니다. 다운로드 출처와 제공된 SHA256을 확인하세요.

## 처음에는 이 버튼만 따라가세요

1. 첫 화면에서 **자료 가져오기**를 눌러 문제 HWPX 또는 HWP를 선택합니다. 정답·해설은 없어도 됩니다.
2. 처리가 끝나면 **가져온 자료 확인** 화면이 자동으로 열립니다. 이제 상단 **지금 할 일**의 큰 버튼을 누르세요. 분리 결과와 객관식·단답형 수를 함께 표시합니다.
3. **의심 문구 확인**이 나오면 원문·사유·수정 제안을 대조합니다. **수정 확인**으로 새 버전을 저장하거나 잘못 잡힌 경고는 **원문 표현 유지**로 표시합니다. 모든 맞춤법·수학 의미를 검사하는 기능은 아닙니다.
4. **정답·해설 생성**을 누르면 대상 문항과 생성 방법을 선택합니다. 지원하는 로컬 수학 유형은 인터넷 없이 풀이하고, 별도 계산·원본 정답 대조를 통과한 문항만 자동 사용합니다.
5. **시험지 만들기**를 누르면 사용 가능한 문항을 담습니다. 제목·순서·배점을 확인하고 **시험 확정**을 누르세요.
6. 확정 뒤 안내의 **출력**에서 문제지·빠른정답·상세해설·유형별 교재를 PDF 또는 HWPX로 저장합니다.
7. **학생 / 반**에서 학생을 등록하고 **시험 / 과제**에서 해당 시험을 **학생 배정**합니다.
8. **성적표**에서 응시를 선택해 **답안 입력/채점**합니다. 채점 뒤 개인 성적표 PDF·반 합본·오답 보완 과제를 저장할 수 있습니다. 다시 배정하면 새 회차이며, 미응시를 별도로 표시합니다.

이미 가져온 자료는 첫 화면의 **자료 열고 다음 작업 보기** 또는 자료실의 **분리·검수 결과 보기**로 이어갑니다. 왼쪽 메뉴를 돌아다니며 다음 버튼을 찾을 필요가 없습니다.

**원문과 대조**는 보존한 원본에서 읽은 텍스트·수식·개체를 현재 문항과 나란히 보여줍니다. 원래 한글 페이지 조판을 보여주는 미리보기는 아닙니다. 오타 수정은 원본 파일을 바꾸지 않으며, 이전 버전과 확정 시험 내용도 유지합니다.

문항검색·변형생성은 왼쪽 메뉴에서 사용할 수 있습니다. 숫자변형·사고변형도 검증 정책을 충족해야 자동 배부할 수 있습니다.

## 정답과 검증

입력 완료와 수학 검증은 다른 상태입니다. 문제만 가져와도 DB 저장·분류·검색할 수 있습니다. 원본 빠른정답은 출처를 보존하고 계산 결과와 대조합니다. 생성 풀이가 원본과 다르면 실패로 표시하며 자동 배부하지 않습니다.

문항 상세의 검증 탭에 검사 정책과 실제 근거를 표시합니다. 지원 정책을 충족하면 사용자 승인 없이 자동 사용 가능합니다. 모든 AI 답변을 정확하다고 가정하지 않으며 동일 모델 재호출의 독립성은 제한됩니다. 문항 수정은 새 버전을 만들고 재검증합니다. 확정 시험과 과거 성적은 이전 내용을 유지합니다.

## 선택적 AI 설정

**설정 → Codex CLI**: 공식 Codex CLI를 Windows에 설치하고 `codex login`으로 로그인합니다. 앱을 다시 연 뒤 연결 검사를 누릅니다. 모델 이름을 비우면 CLI 기본 모델입니다. CLI 로그인 계정의 요금·한도가 적용되며 앱에서 별도 유료 API로 전환하지 않습니다. ChatGPT 웹 대화를 열어 둔 것만으로 로컬 CLI 로그인이 되지는 않습니다.

**설정 → Ollama**: Ollama를 설치·실행하고 사용할 모델을 내려받습니다. 모델 이름을 입력하고 연결 검사합니다. `127.0.0.1:11434`의 로컬 서버만 사용합니다. 모델 정확도와 속도는 보장하지 않습니다.

API 키나 로그인 토큰을 앱의 일반 DB·백업·로그에 저장하지 않습니다. CLI 인증은 CLI가 관리합니다. AI 호출에는 선택한 문제 본문이 해당 제공자에게 전달됩니다.

## 백업과 복원

설정에서 일관된 백업을 만듭니다. DB·원본·그림·출력물을 같은 시점에 저장하고 해시를 기록합니다. 복원은 빈 폴더를 선택합니다. 복원 완료 창에서 **복원한 자료실 열기**를 누르면 새 창에서 열립니다. 나중에는 설정의 **다른 자료실 열기**로 선택합니다. 명령줄 실행을 선호한다면:

```powershell
.\MathBankStudio.exe --workspace "D:\수학자료실\복원"
```

파일·문항 삭제는 휴지통으로 이동합니다. 참조한 시험과 성적은 지우지 않습니다. 영구 삭제는 제공하지 않습니다.

## 문항 분리가 잘못되었으면

자료 화면의 **자동 분리가 잘못되었나요? 원본에서 다시 분석**을 누릅니다. 예전 파서로 잘못 분리된 것으로 판단하면 상단에도 **원본에서 자동 재분리**를 안내합니다. 앱이 보존한 원본으로 처리하므로 파일을 다시 찾거나 원본 번호를 다시 매길 필요가 없습니다.

불확실한 경계는 원문 묶음으로 저장합니다. **문항 경계 확인**을 누르면 시작 문단 후보가 미리 선택되어 있습니다. 문제별 시작 위치를 대조하고 **이 분리안으로 저장**을 누르세요. 후보만으로 확정할 수 없는 자료는 직접 조정이 필요합니다. 이전 분리 결과는 보존하며 **이전 분리로 되돌리기**로 복원할 수 있습니다. 이미 확정된 시험·성적은 바뀌지 않습니다.

기본 오타 검사는 깨진 문자·중복 표현·반복 문장부호 등의 제한된 규칙입니다. 선택적인 **AI 문장검수**는 설정한 모델로 실제 호출하며, 호출 실패를 별도로 표시합니다. 검사 결과 0건이 모든 오타가 없다는 뜻은 아닙니다. AI도 원문을 자동 수정하지 않습니다.

암호·배포용·DRM 자료는 보호를 우회하지 않습니다. 그림·도형·미지원 수식의 보류 사유는 원본과 대조하세요. PDF·사진 OCR은 지원하지 않습니다.

## 이전 버전에서 업데이트

기존 프로그램 창을 닫고 새 ZIP을 **다른 폴더**에 모두 압축 해제한 뒤 새 `MathBankStudio.exe`를 실행하세요. 창 제목과 왼쪽 아래의 **1.1.0**을 확인합니다. 기존 자료실은 `%LOCALAPPDATA%\MathBankStudio`에서 그대로 열립니다. DB를 삭제하거나 원본을 다시 가져오지 마세요.

기존 DB 형식이 1이면 갱신 전에 자료실 `backups` 폴더에 DB 사본을 자동 저장합니다. 이는 DB 사본이며 원본·그림까지 포함하는 전체 백업은 **설정 → 백업**으로 만듭니다. 이전 가져오기가 완전히 실패하여 자료가 없다면 작업 시계에서 **재시도**할 수 있습니다.
