# MathBank Studio 시작하기

## 다운로드와 실행

1. GitHub Releases에서 **MathBankStudio-1.3.0-Windows-x64.zip**을 내려받습니다.
2. ZIP 파일을 오른쪽 클릭하여 **모두 압축 풀기**를 누릅니다.
3. 압축을 푼 `MathBankStudio` 폴더 안의 **MathBankStudio.exe**를 두 번 클릭합니다. `_internal` 폴더도 같은 위치에 있어야 합니다.

Windows 11 x64용입니다. 앱은 로컬 데스크톱 프로그램이므로 접속 주소나 서버 가입은 없습니다. 코드 서명이 없는 배포 파일이므로 Windows가 게시자를 확인할 수 없다고 표시할 수 있습니다. 다운로드 출처와 제공된 SHA256을 확인하세요.

## 실행하면 개별 문항부터 보입니다

1. 첫 화면 **내 문항**에서 **자료 가져오기**를 눌러 HWPX/HWP를 선택합니다. 정답·해설 파일은 없어도 됩니다.
2. 결과는 원본 파일 목록이 아니라 **문제 하나당 카드 하나**로 열립니다. 각 카드에 한 문제의 본문·수식·그림·보기와 개별 단원·난이도를 표시합니다.
3. **문항 열기**로 그 문제의 정답·해설·검증·출처를 확인하거나 **시험에 담기**로 해당 문제만 추가합니다. 여러 문항은 체크해서 **시험에 담기**를 누릅니다.
4. 정답·해설은 체크한 문항의 **정답·해설 생성**으로 처리합니다. 원본 빠른정답이 있으면 대조하고, 지원하는 계산 검사와 별도 풀이를 충족해야 자동 배부할 수 있습니다.
5. **시험 / 과제**에서 제목·순서·배점을 확인하고 **시험 확정**을 누른 뒤 **출력**에서 문제지·빠른정답·상세해설·교재를 저장합니다.
6. **학생 / 반**에서 학생 등록 → 해당 시험의 **학생 배정** → **성적표**에서 **답안 입력/채점** → 성적표·오답 과제 저장으로 이어갑니다.

왼쪽 **문항 DB**는 개별 문제를 관리하는 기본 화면입니다. **원본 파일** 메뉴에는 가져온 원본만 보관합니다. 예를 들어 원본 파일 1개에서 22문항을 읽으면 **문항 DB에는 카드 22개**, 원본 보관에는 파일 1개가 있습니다. 문항을 합쳐 한 문제로 저장한다는 뜻이 아닙니다.

경계가 불확실한 자료는 **분리 대기 원문**으로 따로 표시하며 개별 문항 수에 포함하지 않습니다. **문항 분리 확인**을 누르면 이전 파서 자료는 먼저 새 기준으로 재분석할 수 있습니다. 여전히 불확실하면 자동 제안한 시작 위치를 대조해 저장합니다. 불확실한 여러 문제를 한 문제인 것처럼 표시하거나 임의로 자동 배부하지 않습니다.

## 한 문항씩 별도 파일로 저장

- 카드의 **파일 저장** → HWPX 또는 PDF 선택 → **저장 위치 선택**으로 그 문항 하나만 저장합니다.
- 여러 문항을 체크 → **문항별 파일 저장**을 누르면 **한 문항당 한 파일**을 만들어 ZIP으로 저장합니다. ZIP의 `questions.json`에는 문항 ID·버전·출처 번호와 파일 해시가 들어 있습니다. 한 번에 최대 200문항입니다.
- 원본·문항 DB·이전 시험은 그대로 보존하며, 별도 시험을 만들지 않아도 개별 파일을 저장할 수 있습니다. 정답 검증 전 출력은 초안 표시입니다.

## Windows가 하얗거나 검게 표시되면

1.3.0은 Windows에서 GPU 가속 대신 소프트웨어 렌더링으로 시작하며, 이전 화면 캐시를 재사용하지 않습니다. 화면 연결 실패·표시 프로세스 종료·시간 초과 시에는 웹 화면 대신 Windows 기본 위젯의 복구 안내가 나옵니다.

앱 상단의 **화면 복구 → 화면 다시 열기**는 웹 화면이 표시되지 않아도 사용할 수 있습니다. 복구 안내의 **내 자료실 폴더 열기**로 보존된 자료를 확인할 수 있습니다. 화면 복구는 DB·문항·원본·학생·성적을 삭제하지 않습니다. ZIP은 실행 파일 하나만 꺼내지 말고 전체를 압축 해제하세요.

## 문항별 난이도와 단원별 보기

**시험지 파일 전체에 난이도를 매기지 않습니다.** 분리한 각 문항의 내용과 조건을 기준으로 단원·세부단원·유형·난이도를 따로 저장합니다. 문항별 규칙 추정이며 실제 학생 정답률을 바탕으로 한 난이도가 아닙니다. 객관식/단답형, 원본 파일 이름·학교·번호·배점으로 난이도를 정하지 않습니다.

1. 왼쪽 **문항 DB**를 누릅니다. 가져온 자료 화면에서는 **단원별로 모아보기**를 누르면 해당 자료의 문항부터 볼 수 있습니다.
2. 왼쪽 단원 목록에서 **과목 → 단원 → 세부단원**을 선택합니다. 단원 이름 옆 숫자는 그 분류에 들어 있는 개별 문항 수입니다.
3. 화면 위 **자료 범위**를 `전체 자료의 문항`으로 바꾸면 서로 다른 시험지의 같은 단원 문항을 모아 봅니다.
4. **모든 문항 난이도**에서 하·중·상·미분류를 선택하거나 세부 점수 1~10으로 거릅니다. 쉬운/어려운 문항부터 정렬할 수 있습니다. 하=1~4, 중=5~7, 상=8~10입니다.
5. 문항 카드를 누르면 **이 문항의 단원·난이도**에 점수와 산정 근거가 나옵니다. **분류 수정 → 이 문항만 저장**으로 해당 문제만 수정합니다. 본문·정답·해설·과거 시험/성적은 유지합니다.

가져온 자료 화면에서도 **문항별 단원·난이도 보기**를 펼쳐 원본 번호별 분류표를 볼 수 있습니다. 기본 자동 분류가 근거를 찾지 못하면 **난이도 미분류**, 경계 미확정 묶음은 **분리 후 분류**로 표시하며 임의의 5점을 보여주지 않습니다. 분류 상태와 수학 정답 검증 상태는 별개입니다.

기존 버전의 객관식 5·단답형 7 규칙으로 자동 분류한 값은 새 버전에서 문항별로 다시 제안합니다. 갱신 전 DB 사본을 `backups` 폴더에 보존합니다. 교사가 직접 지정한 값·원본·정답·해설·과거 시험/성적은 유지합니다. **문항 분류 다시 하기**는 현재 검색 결과를 하나씩 처리하며 교사 지정 값은 건드리지 않습니다.

성적표 화면과 PDF에는 문항별 난이도와 하·중·상 문항 수를 표시합니다. 판정할 수 없는 문항은 미분류로 따로 표시합니다.

## 정답과 검증

입력 완료와 수학 검증은 다른 상태입니다. 문제만 가져와도 DB 저장·분류·검색할 수 있습니다. 원본 빠른정답은 출처를 보존하고 계산 결과와 대조합니다. 생성 풀이가 원본과 다르면 실패로 표시하며 자동 배부하지 않습니다.

문항 상세의 검증 탭에 검사 정책과 실제 근거를 표시합니다. 지원 정책을 충족하면 사용자 승인 없이 자동 사용 가능합니다. 모든 AI 답변을 정확하다고 가정하지 않으며 동일 모델 재호출의 독립성은 제한됩니다. 문항 수정은 새 버전을 만들고 재검증합니다. 확정 시험과 과거 성적은 이전 내용을 유지합니다.

## 선택적 AI 설정

**설정 → Codex CLI**: 공식 Codex CLI를 Windows에 설치하고 `codex login`으로 로그인합니다. 앱을 다시 연 뒤 연결 검사를 누릅니다. 모델 이름을 비우면 CLI 기본 모델입니다. CLI 로그인 계정의 요금·한도가 적용되며 앱에서 별도 유료 API로 전환하지 않습니다. ChatGPT 웹 대화를 열어 둔 것만으로 로컬 CLI 로그인이 되지는 않습니다.

**설정 → Ollama**: Ollama를 설치·실행하고 사용할 모델을 내려받습니다. 모델 이름을 입력하고 연결 검사합니다. `127.0.0.1:11434`의 로컬 서버만 사용합니다. 모델 정확도와 속도는 보장하지 않습니다.

API 키나 로그인 토큰을 앱의 일반 DB·백업·로그에 저장하지 않습니다. CLI 인증은 CLI가 관리합니다. AI 호출에는 선택한 문제 본문이 해당 제공자에게 전달됩니다.

## 백업과 복원

설정에서 일관된 백업을 만듭니다. DB·원본·그림·출력물을 같은 시점에 저장하고 해시를 기록합니다. 복원은 빈 폴더를 선택합니다. 복원 완료 창에서 **복원한 자료실 열기**를 누르면 새 창에서 열립니다. 나중에는 설정의 **다른 자료실 열기**로 선택합니다. 명령줄 실행을 선호한다면:

```powershell
.\MathBankStudio.exe --workspace "D:\수학자료실\복원"
```

파일·문항 삭제는 휴지통으로 이동합니다. 참조한 시험과 성적은 지우지 않습니다. 영구 삭제는 제공하지 않습니다.

## 문항 분리가 잘못되었으면

자료 화면의 **자동 분리가 잘못되었나요? 원본에서 다시 분석**을 누릅니다. 예전 파서로 잘못 분리된 것으로 판단하면 상단에도 **원본에서 자동 재분리**를 안내합니다. 앱이 보존한 원본으로 처리하므로 파일을 다시 찾거나 원본 번호를 다시 매길 필요가 없습니다.

불확실한 경계는 원문 묶음으로 저장합니다. **문항 경계 확인**을 누르면 시작 문단 후보가 미리 선택되어 있습니다. 문제별 시작 위치를 대조하고 **이 분리안으로 저장**을 누르세요. 후보만으로 확정할 수 없는 자료는 직접 조정이 필요합니다. 이전 분리 결과는 보존하며 **이전 분리로 되돌리기**로 복원할 수 있습니다. 이미 확정된 시험·성적은 바뀌지 않습니다.

기본 오타 검사는 깨진 문자·중복 표현·반복 문장부호 등의 제한된 규칙입니다. 선택적인 **AI 문장검수**는 설정한 모델로 실제 호출하며, 호출 실패를 별도로 표시합니다. 검사 결과 0건이 모든 오타가 없다는 뜻은 아닙니다. AI도 원문을 자동 수정하지 않습니다.

암호·배포용·DRM 자료는 보호를 우회하지 않습니다. 그림·도형·미지원 수식의 보류 사유는 원본과 대조하세요. PDF·사진 OCR은 지원하지 않습니다.

## 이전 버전에서 업데이트

기존 프로그램 창을 닫고 새 ZIP을 **다른 폴더**에 모두 압축 해제한 뒤 새 `MathBankStudio.exe`를 실행하세요. 창 제목과 왼쪽 아래의 **1.3.0**을 확인합니다. 기존 자료실은 `%LOCALAPPDATA%\MathBankStudio`에서 그대로 열립니다. DB를 삭제하거나 원본을 다시 가져오지 마세요.

기존 DB 형식이 1이면 갱신 전에 자료실 `backups` 폴더에 DB 사본을 자동 저장합니다. 이는 DB 사본이며 원본·그림까지 포함하는 전체 백업은 **설정 → 백업**으로 만듭니다. 이전 가져오기가 완전히 실패하여 자료가 없다면 작업 시계에서 **재시도**할 수 있습니다.
