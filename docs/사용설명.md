# MathBank Studio 시작하기

## 다운로드와 실행

1. GitHub Releases에서 **MathBankStudio-1.0.0-Windows-x64.zip**을 내려받습니다.
2. ZIP 파일을 오른쪽 클릭하여 **모두 압축 풀기**를 누릅니다.
3. 압축을 푼 `MathBankStudio` 폴더 안의 **MathBankStudio.exe**를 두 번 클릭합니다. `_internal` 폴더도 같은 위치에 있어야 합니다.

Windows 11 x64용입니다. 앱은 로컬 데스크톱 프로그램이므로 접속 주소나 서버 가입은 없습니다. 코드 서명이 없는 배포 파일이므로 Windows가 게시자를 확인할 수 없다고 표시할 수 있습니다. 다운로드 출처와 제공된 SHA256을 확인하세요.

## 처음 수업 준비

1. **자료실 → 자료 가져오기**에서 문제 HWPX 또는 HWP를 선택합니다. 정답·해설은 없어도 됩니다. 원본을 앱 자료실로 복사합니다. 작업 시계 아이콘에서 진행 건수와 실패 원인을 확인합니다.
2. **문항검색**에서 본문·자료명·단원·난이도로 찾습니다. 카드를 누르면 문제, 정답·해설, 검증, 출처를 별도로 볼 수 있습니다. 자동 분류는 제안이며 수정할 수 있습니다.
3. 선택 문항 또는 전체 문항의 **정답·해설 생성**을 누릅니다. 로컬 수학 검증기가 지원하는 유형은 인터넷 없이 풀이합니다. AI를 선택하면 설정한 연결로 생성한 후 정답을 숨긴 재풀이와 가능한 계산 검사를 수행합니다.
4. **변형생성**에서 기본 숫자변형 1개, 사고변형 1개를 생성합니다. 로컬 생성기는 다항식 선형 결합·역연산을 지원합니다. 다른 유형은 AI 연결이 필요하며 검증 정책이 없으면 보류됩니다.
5. **학생 / 반**에 학생을 등록합니다.
6. 문항검색에서 문항을 선택하여 **시험에 담기**를 누릅니다. 순서를 끌어 바꾸고 배점·제목·시행일·학원명·단 수를 설정합니다. 초안은 보류 문항을 포함해 검토할 수 있습니다. 확정·학생 배정은 자동 사용 가능 문항만 허용합니다.
7. 시험의 **출력** 버튼에서 문제지, 빠른정답, 상세해설, 유형별 교재를 PDF 또는 HWPX로 저장합니다. 학생 이름을 선택하면 개인용 출력이 됩니다.
8. **성적표**에서 배정한 응시를 선택하고 답안 입력/채점합니다. 수동 점수는 선택 사항입니다. 빈 수동 점수는 자동 채점합니다. 부분정답·무응답·채점대기·미응시를 구분합니다. 다시 배정하면 새 회차입니다.
9. 개인 성적표 PDF, 반별 합본 PDF, 원문·검증된 변형으로 구성한 오답 보완 과제를 생성합니다.

## 정답과 검증

입력 완료와 수학 검증은 다른 상태입니다. 문제만 가져와도 DB 저장·분류·검색할 수 있습니다. 원본 빠른정답은 출처를 보존하고 계산 결과와 대조합니다. 생성 풀이가 원본과 다르면 실패로 표시하며 자동 배부하지 않습니다.

문항 상세의 검증 탭에 검사 정책과 실제 근거를 표시합니다. 지원 정책을 충족하면 사용자 승인 없이 자동 사용 가능합니다. 모든 AI 답변을 정확하다고 가정하지 않으며 동일 모델 재호출의 독립성은 제한됩니다. 문항 수정은 새 버전을 만들고 재검증합니다. 확정 시험과 과거 성적은 이전 내용을 유지합니다.

## 선택적 AI 설정

**설정 → Codex CLI**: 공식 Codex CLI를 Windows에 설치하고 `codex login`으로 로그인합니다. 앱을 다시 연 뒤 연결 검사를 누릅니다. 모델 이름을 비우면 CLI 기본 모델입니다. CLI 로그인 계정의 요금·한도가 적용되며 앱에서 별도 유료 API로 전환하지 않습니다. ChatGPT 웹 대화를 열어 둔 것만으로 로컬 CLI 로그인이 되지는 않습니다.

**설정 → Ollama**: Ollama를 설치·실행하고 사용할 모델을 내려받습니다. 모델 이름을 입력하고 연결 검사합니다. `127.0.0.1:11434`의 로컬 서버만 사용합니다. 모델 정확도와 속도는 보장하지 않습니다.

API 키나 로그인 토큰을 앱의 일반 DB·백업·로그에 저장하지 않습니다. CLI 인증은 CLI가 관리합니다. AI 호출에는 선택한 문제 본문이 해당 제공자에게 전달됩니다.

## 백업과 복원

설정에서 일관된 백업을 만듭니다. DB·원본·그림·출력물을 같은 시점에 저장하고 해시를 기록합니다. 복원은 빈 폴더를 선택합니다. 복원 완료 창에서 **복원한 자료실 열기**를 누르면 새 창에서 열립니다. 나중에는 설정의 **다른 자료실 열기**로 선택합니다. 명령줄 실행을 선호한다면:

```powershell
.\MathBankStudio.exe --workspace "D:\수학자료실\복원"
```

파일·문항 삭제는 휴지통으로 이동합니다. 참조한 시험과 성적은 지우지 않습니다. 영구 삭제는 제공하지 않습니다.

## 입력에 문제가 있으면

불명확한 경계는 한글에서 문항 첫 문단을 `1. `, `2. `처럼 연속 번호로 지정해 HWPX로 저장합니다. 암호·배포용·DRM 자료는 보호를 우회하지 않습니다. 그림·도형·미지원 수식에 보류 사유가 있으면 원본과 대조하세요. PDF·사진 OCR은 지원하지 않습니다.
