기존 앱 파일을 삭제하고, 새 코드·새 화면·독립 DB로 다시 만든 **MathBank Studio 1.0.0**입니다.

**받는 방법**: 아래 Assets의 `MathBankStudio-1.0.0-Windows-x64.zip`을 클릭 → 모두 압축 풀기 → `MathBankStudio/MathBankStudio.exe` 실행. 웹 접속 주소나 Python 설치가 필요하지 않습니다.

문제 HWPX/HWP 가져오기, 정답·해설 별도 생성/검증, 숫자·사고변형, 학생/반, 고정 시험, PDF·HWPX, 채점·오답 과제·성적표, 백업/복원을 연결했습니다. 원본 빠른정답이 없어도 가져올 수 있습니다. 검사 정책을 충족한 문항은 별도 승인 없이 자동 사용합니다.

지원 정책이 없는 문항과 도형 불확실성은 보류합니다. AI는 선택적으로 Codex CLI 또는 로컬 Ollama를 연결합니다. 로컬 변형은 다항식 연산·역연산을 지원합니다. Windows CI는 실제 빌드한 EXE를 실행해 화면 연결과 파일 입출력을 검사합니다. 한글 데스크톱에서 HWPX 열기·수정·재저장은 미검증입니다.

원본 시험·정답·학생 데이터는 공개·포함하지 않았습니다. 이전 MathBankDesktop 실행 파일을 사용하지 않습니다. 자세한 내용은 압축 안의 `시작하기.md`, `지원범위.md`를 참고하세요.
