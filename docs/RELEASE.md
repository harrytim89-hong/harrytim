**MathBank Studio 1.3.0 — Windows 빈 화면 대응 · 문제 하나당 카드·파일 하나**

**받기**: `MathBankStudio-1.3.0-Windows-x64.zip` → 기존 앱 닫기 → 새 폴더에 모두 압축 풀기 → `MathBankStudio/MathBankStudio.exe` 실행. 창 제목의 **1.3.0**을 확인하세요. 기존 DB와 원본은 유지됩니다.

- Windows는 GPU 가속 없이 소프트웨어 렌더링으로 시작합니다. 이전 렌더링 캐시를 재사용하지 않습니다. 화면 로딩 실패나 표시 프로세스 종료 시 빈 화면 대신 Windows 기본 복구 안내를 표시합니다.
- 상단 **화면 복구 → 화면 다시 열기**는 웹 화면과 별개로 작동합니다. 원본·문항·학생·성적을 삭제하지 않습니다.
- 실행과 가져오기 결과를 **문항 DB**로 바꿨습니다. 한 문제의 본문·수식·그림·보기를 카드 하나에 표시하고 **문항 열기·파일 저장·시험에 담기**를 각각 실행합니다.
- 원본 파일은 **원본 파일** 메뉴에 별도로 보관합니다. 원본 1개와 개별 문항 22개를 구분해 표시합니다. 미분리 원문은 개별 문항 수에 넣지 않습니다.
- **파일 저장**으로 한 문항만 PDF/HWPX로 저장합니다. 여러 문항을 체크해 **문항별 파일 저장**을 누르면 한 문제당 파일 하나를 만들어 ZIP에 담습니다.
- 단답형 구간에서 1번부터 번호를 다시 시작하는 형식을 추가 처리합니다. 단원·난이도 필터, 개별 정답·해설 생성과 시험·채점 기능은 연결됩니다.
- 작은 창·확대 배율에 맞춰 메뉴·카드·버튼·팝업 배치를 조정했습니다.

Windows 기본 창 모드에서 배율 100%·150%·200% 각각 EXE를 실행해 화면 픽셀·복구·개별 카드·개별 파일 저장과 가져오기부터 출력·채점까지 검사합니다. 자동 검사는 사용자의 특정 그래픽 드라이버에서 증상이 재현·해결됐다는 보증은 아닙니다. 난이도는 내용 기반 추정이며 불명확한 경계·수학 조건은 보류합니다. 사용자 원본·정답·학생 DB는 공개하지 않습니다.
