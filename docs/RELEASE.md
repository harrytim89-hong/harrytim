**MathBank Studio 1.2.0 — 문항별 난이도·단원 분류**

**다운로드**: Assets의 `MathBankStudio-1.2.0-Windows-x64.zip` → 모두 압축 풀기 → `MathBankStudio/MathBankStudio.exe` 실행. 창 제목의 **1.2.0**을 확인하세요.

- 시험지 전체에 하나의 난이도를 부여하지 않고 **각 문항**의 단원·세부단원·유형·난이도 1~10과 근거를 표시합니다. 객관식 5·단답형 7로 고정하던 규칙을 없앴습니다.
- 왼쪽 **단원별 문항**에서 과목 → 단원 → 세부단원을 누르면 해당 문항을 볼 수 있습니다. 자료 범위를 전체로 바꾸면 여러 시험지의 같은 단원 문항을 모아 봅니다.
- 난이도 하(1~4)·중(5~7)·상(8~10), 세부 점수 필터와 쉬운/어려운 순서 정렬을 추가했습니다.
- 가져온 자료의 **문항별 단원·난이도 보기** 표와 **단원별로 모아보기** 버튼을 추가했습니다.
- **분류 수정 → 이 문항만 저장**으로 개별 분류를 수정합니다. 정답·해설·원본·과거 시험/성적은 유지합니다.
- 성적표와 PDF에도 각 문항의 난이도를 표시합니다. 시험 평균 난이도 대신 하·중·상 문항 수를 보여줍니다.

기존 앱을 닫고 새 ZIP을 다른 폴더에 모두 풀어 실행하세요. 기존 자료는 그대로 열립니다. 예전 자동 분류는 DB 사본을 보존하고 문항별로 갱신하며, 교사가 지정한 값은 유지합니다. 원본 재업로드나 DB 삭제는 필요 없습니다.

난이도는 내용·조건별 규칙에 따른 **추정**이며 실제 정답률로 보정한 값은 아닙니다. 근거가 부족하면 미분류, 경계 미확정 묶음은 분리 후 분류로 남깁니다. 문항 분류와 수학 정답 검증은 별개입니다.

Windows 실행 파일에서 단원 선택 → 난이도 필터 → 개별 분류 수정 → 새 단원 목록 반영 → 이전 시험 내용 보존을 실제 화면 버튼으로 검사합니다. 가져오기부터 출력·채점·성적표 저장 검사도 포함합니다. 원본 시험·정답·학생 DB는 배포하지 않습니다.
