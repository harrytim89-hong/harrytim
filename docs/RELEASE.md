**수학비서 · MathBank Studio 1.4.0**

문항 은행에서 원본 문항을 열면 동일·유사 문항을 바로 찾고, 나란히 비교한 뒤 시험에 담거나 기존 문항을 교체할 수 있습니다.

- 네이비·민트 UI, 실제 자료실 현황, 중등·고등·공통 범위 탭, 24문항 단위 목록과 단원·난이도 필터.
- 본문, 수식 AST, 보기 순서, 그림 내용 해시를 비교하는 동일 문항 검색. 수치를 제외한 표현·단원·유형 및 저장된 변형 연결을 활용하는 유사 후보 검색. 검색 점수와 근거를 표시합니다.
- 비교 창에서 시험에 추가하거나 기준 문항을 교체합니다. 교체 시 순서·배점을 유지하며 기존 확정 시험은 바뀌지 않습니다.
- 학교 범위와 난이도는 문항별로 수정하고 저장할 수 있습니다. 중·고 공통 범위는 양쪽 필터에 표시됩니다.
- 기존 성적표의 점수·단원별 성취·문항별 기록에 취약 유형과 교사 코멘트를 추가했습니다. 코멘트는 응시별 DB에 저장하고 개인·반별 PDF에 반영합니다. 미채점 문항을 오답으로 단정하지 않습니다.
- HWP/HWPX 가져오기, 개별 문항 PDF/HWPX/ZIP, 시험지·정답·해설 출력, 학생 배정, 채점, 오답 과제, 백업·복원 기능을 유지합니다.

기존 자료실은 그대로 사용합니다. 새 버전 실행 전 기존 앱을 닫으세요. 화면의 예제는 검증용 자체 작성 문항과 가상 학생이며 사용자 자료는 포함하지 않습니다.

HWP의 모든 서식·도형을 완전 처리하거나 규칙 기반 난이도·유사도를 무오류로 보장하지 않습니다. 지원하지 않는 내용은 검수 대상이며, 한글 데스크톱에서의 편집·재저장 호환성은 별도 확인이 필요합니다. 다른 ChatGPT 대화의 최근 성적표 양식은 이 작업에서 조회하지 못했으므로 저장소의 기존 성적표를 기준으로 개선했습니다.
