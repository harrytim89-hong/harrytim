**MathBank Studio 1.0.1 — 문항 경계를 확인하지 못해 가져오기가 실패하는 문제 수정**

**받는 방법**: 아래 Assets의 `MathBankStudio-1.0.1-Windows-x64.zip`을 클릭 → 모두 압축 풀기 → `MathBankStudio/MathBankStudio.exe` 실행.

- 번호 뒤 공백이 없는 `1.본문`, `01.`, `21.`부터 시작하는 발췌, 괄호 번호, `[문제 1]`, 문단 자동 번호를 추가 처리합니다.
- 표·글상자 안에 배치된 문항, 단일 문항 자료, 객관식 없는 정답 미주도 처리합니다.
- 일반 각주를 정답 미주와 함께 제거하던 문제를 수정했습니다.
- 불분명한 경계는 전체 가져오기를 실패시키지 않고 원문을 ‘경계 확인 필요’로 저장합니다. **문항검색 → 해당 카드 → 문항 나누기**에서 시작 문단만 선택하면 됩니다. 불확실한 자료는 자동 배부되지 않습니다.
- ‘저장 보류’와 ‘파일 처리 실패’를 작업 내역에 구분합니다.

업데이트할 때 기존 앱 창을 닫고 새 ZIP을 다른 폴더에 압축 해제해 실행하세요. 기존 자료실·학생·시험·성적 기록은 유지합니다. 이전 실패 작업은 시계 아이콘의 **재시도** 또는 같은 파일 다시 가져오기로 처리할 수 있습니다. 원본 번호를 다시 매기거나 DB를 삭제할 필요가 없습니다.

Windows에서 새 EXE를 실행하여 원문 저장→문항 나누기→정답 생성→PDF/HWPX→채점→백업/복원 및 화면 연결을 검사합니다. 사용자 원본 시험·정답·학생 DB는 배포 파일에 포함하지 않습니다.
