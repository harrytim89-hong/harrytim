# 0.2.2 작업 큐 시작 수정

작업 큐의 **자동 처리 시작 · 재개** 버튼을 누르면 현재 세션의 Codex 구독 연결을 켜고 대기/중단 작업을 처리합니다. 설정 화면에서 먼저 연결을 켤 필요가 없습니다. 이미 취소한 작업은 일괄 재개하지 않으며, 필요하면 선택 예외 재시도를 사용하세요.

큐 상단에는 전체 대기/실행/중단/완료 수와 실행 상태를 표시합니다. 표는 최근 300건만 표시하지만 상단 집계는 전체 작업 기준입니다. 인증·한도·Codex 실행 오류로 중단되면 사유가 표시됩니다. 원인을 해결하고 시작 · 재개를 누르세요. 프로그램을 다시 열면 연결은 꺼져 있으므로 같은 버튼으로 시작하세요.

기존 프로그램을 닫고 새 ZIP 전체를 새 폴더에 풀어 MathBankDesktop.exe를 실행하세요. PDF를 다시 등록할 필요는 없습니다. 운영 데이터는 기존 데이터 폴더를 계속 사용합니다.

검증: 가짜 AI 처리기를 이용한 300건 연속 처리, 오류 후 재개, 취소 작업 유지 테스트 포함. 실제 PC의 Codex 오류 해결이나 300문항 AI 정확도 검증을 의미하지 않습니다.
