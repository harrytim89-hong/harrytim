# MathBank Desktop 0.4.0

## 원본 도형을 정확히 보존

신규 자동처리는 AI에 도형 좌표 재작성을 요청하지 않습니다. 원본 문항을 보존하고 전사·풀이·독립 판독·원본 대조를 계속 수행합니다. 풀이가 원본 도형의 관계를 잘못 해석하면 최종 검토에서 예외로 남습니다. AI 검토는 수학적 정확성의 보장이 아닙니다.

시험지 생성 시 원본 스캔 보존(권장)을 선택하면 기존 문항에도 적용됩니다. 기존에 저장한 시험지는 불변 스냅샷이므로 새 시험지를 만들어야 합니다. PDF와 Word 모두 원본 이미지가 포함됩니다. 원본 이미지를 시험지에 내장해 이후 원본 파일 변경/삭제에 영향받지 않으며 저장 용량은 증가합니다.

문항 영역 전체를 보존하므로 교재의 원래 번호, 배경, 필기, 인쇄 상태도 유지됩니다. 원본에 이미 잘못 지정된 문항 영역이나 잘린 그림은 복구하지 못합니다. 영역이 잘못되었으면 먼저 수정하세요. 원본 이미지에는 편집한 전사 내용이 반영되지 않습니다. Word에서도 원본 영역은 이미지이며 편집 가능한 수식이 아닙니다. 수동 편집 문항은 편집·재작성 모드로 출력할 수 있습니다. 신규 원본 보존 문항은 재작성 모드를 골라도 원본을 사용해 도형 누락을 방지합니다.

## 불필요한 재시도 감소

수식 내부의 dfrac/tfrac/frac 표시 방식과 left/right 크기 지정 차이만 정규화합니다. 숫자·부호·지수·조건 차이는 여전히 검사합니다. 수학적 동치라고 추측해 다른 수식을 통과시키지 않습니다.

## 선택: PC에서 독립 판독

설정의 '로컬 독립 판독 (실험 기능)'에 설치된 Ollama 비전 모델 이름을 넣습니다. Ollama는 별도 설치가 필요하며 앱은 모델을 다운로드하지 않습니다. Ollama가 127.0.0.1:11434에서 실행돼야 합니다. 모델의 초기 다운로드·로딩은 사용자가 먼저 완료해야 합니다. 비전 기능과 한국어 수식 인식이 가능한 모델이 필요합니다.

RTX 4060과 RAM 32GB에서는 작은 양자화 비전 모델을 우선 비교할 수 있지만 실제 VRAM, 다른 프로그램의 점유량, 모델과 이미지 크기에 따라 메모리 부족이나 CPU 처리로 인한 지연이 생길 수 있습니다. 이 버전은 사용자 PC에서 GPU 사용·정답률·속도를 검증하지 않았습니다. 검증된 특정 모델을 기본 제공하지 않으며 처음에는 이 입력을 비워 기존 Codex 판독을 유지하세요.

로컬 옵션은 독립 판독만 교체합니다. 페이지 분리, 풀이 생성, 최종 검토는 Codex 구독을 계속 사용합니다. 로컬 판독은 후보 풀이를 전달받지 않고 원본 이미지만 읽습니다. 로컬 실패 시 구독 호출로 자동 전환하지 않고 중단 사유를 표시합니다. 입력을 비우고 설정 저장 후 재개하면 기존 방식으로 돌아갑니다.

로컬 요청은 모델을 최대 10분 유지하도록 요청해 반복 로딩을 줄이고 한 번에 하나씩 실행합니다. 문맥 4096, 출력 2048 제한이며 불완전 응답은 실패 처리합니다. 네트워크 응답 대기 제한은 30초이며 취소도 응답 또는 시간 초과 이후 처리될 수 있습니다. 로컬 모델이 느리거나 전사 오류가 많으면 총시간이 오히려 늘 수 있습니다.

## 검증 범위

원본 PNG 바이트가 시험지와 DOCX에 그대로 내장되는지, 원본 파일 변경 시 차단되는지, 독립 판독 표기 정규화가 숫자·부호 오류를 숨기지 않는지, 로컬 요청의 형식·실패·취소 동작을 자동 검사합니다. 로컬 AI는 모의 HTTP 응답으로 검사합니다.

제공된 7개 예시는 그래프·기하·음영·필기가 섞인 자료라는 설계 참고로 사용했습니다. 이 이미지들에 대한 실제 AI 전후 정답률·처리시간 비교는 수행하지 않았습니다. GeoGebra/Desmos 연동, 페이지 전체 수식 OCR, 문항 묶음 처리, 전 과정 로컬 실행은 이번 버전에 포함되지 않습니다. 실제 교재 전체의 속도 향상률이나 정확도 동등성은 보장하지 않습니다.
