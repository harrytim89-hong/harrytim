# 새 구현 검증 기록

기존 프로젝트의 애플리케이션·테스트·빌드 파일과 이전 산출물을 삭제한 후 `studio/`를 새로 작성했습니다. Git 이력과 사용자 첨부 입력만 보존했습니다. 이력 보존은 기존 앱을 재사용한다는 의미가 아닙니다.

새 테스트는 기존 테스트를 복사하지 않았으며 자체 작성한 HWPX와 네이티브 HWP 변환 자료를 사용합니다. 실제 사용자 시험 원본·정답·학생 DB는 공개하지 않습니다.

검사 연결:

1. 문제만 있는 파일 / 정답 미주 파일 → 문항 분리 → 원본/수식/그림 참조 보존 → 중복 감지.
2. 원본 정답을 숨긴 계산 → 별도 계수·해·정의역·분모·완전 탐색 등 유형별 검사 → 원본 대조. 미지원·충돌·복수 정답은 차단.
3. 원본 불변 숫자변형·사고변형, 작업 키로 중복 저장 방지.
4. PDF/HWPX 4가지 출력, PDF 텍스트 추출과 렌더링, HWPX 재열기.
5. 학생 배정, 자동/부분/무응답 채점, 미응시 제외, 재시험 회차, 오답 과제.
6. 문항 수정 후 과거 시험·성적 불변, 오래된 작업 결과 적용 거절.
7. 해시 백업→새 폴더 복원→DB 무결성·참조·점수 대조.
8. 악성 수식 코드 문자열, ZIP 경로 탈출, 손상 백업, AI 연결 부재.
9. QtWebEngine의 실제 QWebChannel 통신과 수식 렌더링.

Linux에서 새 테스트 34개를 통과했습니다. Windows 결과는 해당 커밋의 GitHub Actions와 배포 파일의 `studio-selftest.json`으로 기록합니다. 빌드가 실패하면 릴리스를 만들지 않습니다.

실제 첨부 파일도 새 가져오기 코드로 22문항과 미주 정답 22개를 읽었으며 수식 207개·텍스트 160문단·원본 표/그림 수를 변환 전후 대조했습니다. 개인정보·원본 문제 내용이 포함된 검사 산출물은 공개하지 않습니다. 실제 문항 전체의 무오류나 모든 입력 양식 지원을 선언하지 않습니다.

실제 파일의 22문항 모두 정답·상세해설을 별도 계산했습니다. 21문항은 정책 검사와 원본 정답 대조를 통과했고, 원본 그림 관계를 독립적으로 확인하지 못한 1문항은 계산 결과를 저장하되 자동 배부를 보류했습니다. 생성식의 문법·정의역·모든 보기 비교와 알려지지 않은 추가 조건 차단을 검사합니다.

Codex CLI 0.163.0의 설치·로그인을 확인했으나 이 개발 환경은 CLI 실행 기록 폴더가 읽기 전용이어서 실제 모델 호출이 실패했습니다. 연결 실패를 성공으로 처리하지 않았으며 로컬 수학 생성·검증 경로로 전체 연결을 확인했습니다. 사용자 PC의 모델 호출은 연결 설정 후 확인해야 합니다.

실제 입력에서 정답·상세해설·유형별 교재·문제지의 PDF/HWPX 8개와 개인 성적표를 생성했습니다. 23문항(검사 통과 원문 21개와 변형 2개)의 가상 응시에서 부분정답·무응답을 반영한 107.5/115점을 확인했습니다. 원문·숫자변형 오답 과제, 재응시·미응시, 시험 불변성, 백업의 새 폴더 복원도 확인했습니다. 이는 실제 학생 성적이 아닌 분리된 검사 DB의 결과입니다.
